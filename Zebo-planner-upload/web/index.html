    Architecture & governance

    Deterministic code does the calculations. The advisor chooses tools and explains results. A human decides.

    Workflow

    1. User questionPlain language
    2. Intent router / optional modelRule-based by default
    3. Allowlisted read-only toolValidated args · max 3 calls
    4. Deterministic calculationPython, from CSVs
    5. Evidence-grounded responseFigures checked vs tool output
    6. Human reviewPlanner decides
    7. Draft-only change requestPENDING_HUMAN_APPROVAL · executed: false

    Boundaries

    • Synthetic data only.
    • Read-only analysis; no writes to business systems, CRM, email, or external services.
    • Human approval required for consequential decisions; drafts are never applied.
    • Numeric claims must be traceable to data/tool results (automated grounding check).
    • No employee ranking, termination, or individual performance decisions; rep data shown only in aggregate.
    • No unsupported claims about savings, accuracy, or production readiness.
    • Tool calls and review decisions are logged locally without questions, secrets, or personal data.
    • Thresholds are illustrative demo thresholds requiring business-owner validation.
